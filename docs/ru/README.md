# Russian originals

The project's documents were written in Russian and translated into English on
2026-09-10, when the owner made English the working language. The English versions
in the repository and on <https://keweegen.github.io/calyx> are the ones that are
maintained; the files in this directory are the originals they were translated from.

**Where the two differ, the Russian text governs.** That matters for the sections
written before a run and never edited afterwards — whitepaper 5.8, 5.9, 6.5, 6.5a,
6.5b and specification 3zh, 3z, 3i — because their point is that the wording was
fixed before the outcome was known, and a translation is new wording.

For the specification there is a stronger record than this snapshot: the
pre-registration of each stage is the byte copy stored next to its hash under
`results/` (`experiment-spec-h1-h3.v0.17.frozen.md` and `636c4996…` for V1c). Those
copies are untouched and remain the authority for anything a stage's criteria say.
The whitepaper and the sparseness note were never hashed, which is why this snapshot
exists: without it the English text would have no original to point back to.

`sha256.txt` carries the size and digest of each file. Nothing here is edited.
