# Журнал диагностического измерения E6.2

Запись по правилу Е1. Составлена до запуска уточнения разрешения; основной
проход к моменту этой записи выполнен и его результат приведён ниже как
исходное состояние.

## Е1. Объявление измерения

**Название.** Диагностика зазора между окном доли отвечающих KC и окном частот
MBON. Перечислена в штампе 0 ступени V1c как V1c-E6.2.

**Статус.** Диагностическое, некритериальное. Ни один критерий по нему не
вычисляется, ни один параметр не выбирается.

**Оси и диапазоны.** `pn_kc_scale` — два значения, 8 и 4. `g_apl` — от 0 до
3,16228, то есть от нуля до максимума сетки стадии 2 ступени V1b′.

**Протокол.** Тайминг M: предъявление 5 000 мс, окно измерения 5 000 мс от
`t_on`. Стимулы — калибровочный набор C из шести одорантов (2-heptanone,
isopentyl acetate, hexanal, 6-methyl-5-hepten-2-one, diethyl succinate, methyl
octanoate); набор E не расходуется. Число проб 2. Зёрна `SEED_CAL_M` + 1…2, то
есть 20 260 959 и 20 260 960 — первые две пробы того же отрезка, который
ступень V1b′ использовала для ограничения допустимости. `kc_mbon_scale` = 1 без
исключений (правило Е5: ручка ступени, чей штамп 0 захэширован, не варьируется).
Маска подмен и градуальный APL — как в ступени.

**Наблюдаемые.** Число спайков KC и MBON за окно; число MBON, давших хотя бы
один спайк; частота типа `R_t` по шести типам T₃₈, считаемая функцией
`mbon_type_rates` ступени.

**Выходы.**
1. Интервал `g_apl`, где среднее по запахам C значение `f(o)` лежит в полосе
   [0,03; 0,10] при `max f(o) ≤ 0,10`.
2. Интервал `g_apl`, где `R_t` лежит в коридоре [2; 67] Гц у всех шести типов.
3. Доля отвечающих KC там, где минимум `R_t` по типам пересекает пол 2 Гц.

Выход 1 не пересчитывается прогоном, а читается из артефактов калибровки V1b′:
правило V1b-2.1–2.3 требует ответа не менее чем в трёх пробах из шести и на
двух пробах недостижимо. Источник — `results/v1b_prime/calibration_stage1.json`
и `calibration_stage2.json`, 6 проб, зёрна `SEED_CAL`.

**Начальный набор узлов по `g_apl`.** 0; 0,01; 0,031623; 0,1; 0,17783; 0,31623;
0,56234; 1,0; 1,7783; 3,16228 — десять значений, все, кроме нуля, суть узлы
сетки стадии 2 ступени V1b′.

## Исходное состояние: результат основного прохода

Масштаб 8. Окно доли: `g ∈ [1,7783; 3,1623]`, три узла. Минимум `R_t` по шести
типам: 38,0833 Гц при `g = 0`; 0,0000 Гц при `g = 0,01` и во всех узлах правее.
Максимум `R_t`: 243,7333 Гц при `g = 0`; 136,1583 при 0,01; 81,4667 при
0,031623; 18,9875 при 0,1. Коридор не выполнен ни в одном узле.

Масштаб 4. Окно доли: `g ∈ [0,4217; 1,3335]`, пять узлов. Минимум `R_t`:
**1,5917 Гц при `g = 0`**, то есть ниже пола 2 Гц уже в наиболее благоприятной
точке оси; 0,0000 Гц при `g = 0,01` и правее. Максимум `R_t`: 201,3667 Гц при
`g = 0`. Коридор не выполнен ни в одном узле.

Выход 2 при этом разрешении получен как «пусто», выход 3 — как вилка `(0; 0,01)`
при масштабе 8, то есть количественно не определён.

## Е2. Правило уточнения разрешения

Записано до запуска уточнения. Ось прежняя (`g_apl`), диапазон прежний,
протокол и наблюдаемые не меняются, поэтому уточнение есть исполнение
объявленного выхода, а не новое измерение.

**Правило выбора узлов, для каждого масштаба независимо.**

- Вилка `(g_lo; g_hi)` — пара соседних посчитанных узлов, между которыми
  минимум `R_t` по шести типам пересекает пол 2 Гц: на `g_lo` минимум не ниже
  пола, на `g_hi` — ниже.
- **Шаг 1.** Пока `g_lo = 0` или минимум `R_t` на `g_lo` меньше 2 Гц — делить
  вилку пополам линейно: новый узел `(g_lo + g_hi) / 2`.
- **Шаг 2.** Когда `g_lo > 0` и минимум `R_t` на `g_lo` не ниже 2 Гц — делить
  пополам в логарифмической шкале: новый узел `sqrt(g_lo · g_hi)`, пока
  `g_hi / g_lo > 1,25`.
- **Предел: не более 8 добавленных узлов на масштаб.** При исчерпании предела
  вилка сообщается как есть.
- **Вырожденный случай.** Если вилки не существует, потому что минимум `R_t`
  ниже пола уже в наиболее благоприятной точке оси `g = 0`, уточнение не
  выполняется: пересекать нечего. В этом случае добавляются **два** узла внутрь
  `(0; 0,01)` как проверка монотонности минимума по `g_apl`, и это включено в
  предел восьми.

**Форма отчёта.** Выход 3 сообщается парой значений на концах финальной вилки, а
не одним числом. Выход 2 при пустом результате сообщается как «∅ при данном
разрешении» вместе с двумя производными величинами (правило Е4, «производная
величина», критерием быть не может):

- `g₆₇` — наибольшее `g`, при котором максимум `R_t` по шести типам ещё выше 67 Гц;
- `g₂` — наименьшее `g`, при котором минимум `R_t` уже ниже 2 Гц.

Коридор пуст на сетке тогда и только тогда, когда `g₆₇ ≥ g₂`.

**Узлы, посчитанные основным проходом, не пересчитываются и не заменяются:**
порядок решений сохраняется в артефакте.

## Предрегистрированная контингенция

Если уточнение обнаружит значение `g_apl`, при котором одновременно выполнены
полоса разреженности [0,03; 0,10] и коридор [2; 67] у всех шести типов, то
сетка V1b′ по `g_apl` признаётся слишком грубой, ступень V1c не исполняется, её
штамп 0 закрывается записью «не исполнен, основание — E6.2», и открывается
ступень V1b″ с уточнённой сеткой по `g_apl`.

Проверка условия по доле не требует прогона. Доля отвечающих KC монотонно
убывает по `g_apl` на всех 25 измеренных узлах при обоих масштабах, а на нижнем
измеренном узле `g = 0,01` она равна 0,5861 при масштабе 8 и 0,4812 при
масштабе 4. Уточнение добавляет узлы только **левее** 0,01, где доля не меньше
этих значений, то есть впятеро выше потолка 0,10. Следовательно, контингенция
сработать не может, и это записано до запуска уточнения, а не после.

## Е2, вторая запись: уточнение узлов выхода 1

Записана после уточнения по `g_apl` и **до** прогона, который она объявляет.

Финальная вилка выхода 3 при масштабе 8 — `(0,00148650889; 0,00176776695)` —
лежит левее нижнего узла калибровочной сетки V1b′ (`g = 0,01`). Доля отвечающих
KC на её концах поэтому в артефактах ступени отсутствует, и выход 3
количественно не определён: по монотонности известна только нижняя оценка.

**Правило выбора узлов.** Ровно два узла: оба конца финальной вилки выхода 3 при
масштабе 8. Ни одного узла больше не добавляется. Если бы вилка была
недоопределена, узлы не добавлялись бы вовсе.

**Протокол — тот же, что у источника выхода 1**, и в этом смысл ограничения:
тайминг P14 (импульс 1 000 мс, окно 4 000 мс), шесть проб, зёрна `SEED_CAL`
+ 1…6, набор C, правило V1b-2.1–2.3 «не менее одного спайка не менее чем в трёх
пробах из шести», функция `evaluate_point` ступени. Ось, диапазон и наблюдаемые
прежние, поэтому по правилу Е2 это исполнение объявленного выхода.

`kc_mbon_scale` = 1 (правило Е5).
